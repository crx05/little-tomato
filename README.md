# 小番茄 · 小学生作业专注时钟

一个独立、无需安装前端依赖的中文网页应用，使用 HTML、CSS、原生 JavaScript 实现。没有账号、网络字体、外部脚本或服务端依赖。

现已加入 **安卓离线 App 工程与息屏提醒**。安卓打包、APK 安装、权限设置和验证状态见 [ANDROID.md](ANDROID.md)。网页运行方式保持不变；安卓构建需要额外安装开发依赖和 Android SDK。

## 运行

在项目根目录运行：

```bash
python3 -m http.server 4311 --directory designs
```

打开 <http://localhost:4311/homework-tomato/>。也可把 `homework-tomato` 整个文件夹部署到任意静态网站服务。直接打开 `index.html` 也能计时，但建议使用上述本地服务，以获得一致的存储和桌面提醒行为。

## 产品规划与已实现功能

1. **准备**：添加作业小任务，选择语文、数学、英语或其他学科；选定本轮目标，也可以直接自由专注。
2. **专注**：默认 20 分钟，提供 15 / 20 / 25 分钟快捷选项，可设置 1–60 分钟；支持开始、暂停、继续、重新计时和沉浸模式。
3. **休息**：默认短休息 5 分钟、长休息 15 分钟；每完成当天第 4、8、12…轮专注，建议一次长休息。均由用户主动开始，不自动连播下一轮。
4. **提醒**：页面弹窗、轻柔提示音和可选的浏览器桌面提醒。设置中可试听提示音、关闭声音、调整时长及每日小目标。
5. **收获**：完成一整轮才获得一颗番茄；显示当天专注分钟、番茄数、累计专注天数、最近七天的分钟数及当天记录。每日目标默认 4 颗，可设置 1–12 颗。
6. **作业清单**：选择任务、完成或重新打开、确认后删除。完成一轮专注和完成作业是两件独立的事；删除任务不会删除过去的专注记录。任务会保留到手动完成或移除，适合跨天继续。

## 面向孩子的设计

- 奶油白、番茄红与柔和绿，大号数字和简短操作文字；支持电脑、平板与手机。
- 一次只处理一个小目标；专注中避免误换目标，重新开始和切换模式会确认。
- 用积极、具体的反馈代替排名、惩罚或连续打卡压力。
- 休息鼓励离开屏幕、喝水和看远处；尊重系统的减少动画设置。
- 使用语义化按钮、表单标签、键盘焦点与原生对话框；倒计时不逐秒打断屏幕阅读器。

## 计时与数据规则

- 计时使用绝对结束时间。页面后台节流后恢复显示时，按实际时间校准；暂停时间不计入专注。
- 每次状态变化写入 `localStorage`（键为 `little-tomato:v1`）。刷新后可恢复运行或暂停状态；在结束弹窗上刷新不会重复获得番茄。
- 完成时间按计划结束时刻保存，按设备本地日期归档。跨午夜计入结束日；隔天重新打开不会把昨天结束的专注误算到今天。
- 保留最近 1000 条专注记录与最多 100 项任务，累计天数基于当前保留记录。清空浏览器数据会清除记录；不同浏览器或设备之间不自动同步。
- 同一来源的标签页通过 `storage` 事件同步状态。建议在一个标签页操作；同时编辑以最后写入为准。
- 存储损坏时恢复可用默认状态，存储不可写时页面会提示；任务文本使用转义输出。

浏览器关闭、设备锁屏或系统挂起时，网页不能保证准时发声或发送通知；重新打开时会校准并显示结束结果。需要准时提醒时，请保持页面打开、设备唤醒并允许声音。桌面提醒需要浏览器支持和授权（通常为 localhost 或 HTTPS），拒绝权限后仍有页面弹窗。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 语义化页面及对话框 |
| `styles.css` | 界面风格、移动布局及沉浸模式 |
| `core.js` | 独立的计时状态、任务、记录与数据校验 |
| `app.js` | 界面操作、持久化、声音及桌面通知 |
| `tests/core.test.cjs` | 核心计时和恢复逻辑测试 |
| `tests/browser_test.py` | 浏览器操作及响应式测试，需要 Playwright |

## 验证

核心测试无需安装依赖：

```bash
node --test designs/homework-tomato/tests/core.test.cjs
```

浏览器测试使用 Python Playwright，默认访问上面的本地服务：

```bash
python3 designs/homework-tomato/tests/browser_test.py
```

也可设置 `TOMATO_TEST_URL`、`TOMATO_CHROMIUM`，或传入 `--intercept` 使用浏览器请求拦截从本地文件供给页面，适用于无法启动监听端口的验证环境。

当前验证：23 项 JavaScript 测试通过（12 项核心计时、9 项原生桥接与恢复、2 项构建引导）；JavaScript 语法、页面 ID、静态控件选择器、本地资源、图标引用和安卓 XML 检查通过。当前环境限制本地服务与 Chromium 启动，且缺少 Android 构建依赖，因此浏览器验收、安卓编译、7 项原生测试和真机息屏验证仍待执行。详见 [ANDROID.md](ANDROID.md)。
